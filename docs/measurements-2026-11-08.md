## Py1812

- https://github.com/eeveetza/Py1812 (Ivica Stevanovic, Swiss OFCOM), ITU-R P.1812-8 (2025-09). No releases or tags; __version__ "8.0"; latest commit 6c9061dd 2026-08-28. Licence: custom permissive notice (as-is, modify and redistribute freely, change notice on modified works, acknowledgement requested). Not on PyPI. Install from git; flit_core; numpy only; README says tested on 3.9.
- Python 3.12.2 uv venv: installs (uv needs --native-tls here), numpy 2.5.4. Import fails until the ITU maps are installed: https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.1812-8-202509-I!!ZIP-E.zip (636 KB, public), copy N050.TXT and DN50.TXT into the package maps/ folder, run initiate_digital_maps.py from inside the package folder (writes P1812.npz to cwd). ITU files must not be committed or redistributed; the build writes inside site-packages, so ADR 0006 should weigh a wrapper that builds the npz into a data directory, or a vendored fork, plus a loud failure when the npz is missing.
- Test call: flat inland 10 km path, 150 m asl, 0.915 GHz, p 50, 2 m antennas, vertical, zone 4, St. Louis latitude: Lb 149.48 dB, Ep 49.11 dBuV/m (FSPL 111.68 dB, so 37.8 dB smooth-earth diffraction, the right order).
- Inputs: P1812.bt_loss(f GHz 0.03 to 6, p percent 1 to 50, d km ascending from Tx, h m asl array, R clutter height m array, zone int array (1 sea, 3 coastal, 4 inland), htg, hrg m, pol 1 or 2, phi_t, phi_r, lam_t, lam_r deg; optional pL, sigmaL, Ptx kW, Gtx, Grx dBi, DN, N0, dct, dcr, flag4, debug) returning (Lb dB, Ep dBuV/m). R is where DSM minus DEM and canopy enter; zone is 4 everywhere in the MSA.
